# LegalInkPack Examples

This directory contains example scripts demonstrating various features of LegalInkPack.

## Available Examples

### basic_usage.py

Demonstrates basic functionality:
- Initializing the toolkit
- Checking status
- Listing capabilities
- Running scans

**Run:**
```bash
python examples/basic_usage.py
```

### advanced_usage.py

Demonstrates advanced features:
- Configuration management
- Input validation
- Error handling
- Logging

**Run:**
```bash
python examples/advanced_usage.py
```

## Prerequisites

Ensure LegalInkPack is installed:

```bash
pip install -e .
```

Or install with development dependencies:

```bash
pip install -e ".[dev]"
```
